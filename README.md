# [Shared Folders](https://modrinth.com/project/sharedfolders)
## Fabric 26.x
### Synchronize folders in your instance by using the default .minecraft folder.

# THIS MOD IS IN EARLY DEVELOPMENT, USE AT YOUR OWN RISK
_I still felt the strong urge to share this anyways :)_

SharedFolders is a mod allowing you to synchronize the folder of your instance with the .minecraft folder in %appdata%. For example you can now synchronize all your shaders, resourcepacks and screenshots across every instance. Together with a mod like [Screenshot Gallery](https://modrinth.com/mod/screenshot-gallery) you could always look at every screenshot you ever made.

I'm looking to add support for all versions after 26.x for Fabric, NeoForge, Forge (In order of priority). I won't add new features to old versions.
